# LegalSangam ⚖️

LegalSangam is a comprehensive platform designed to bridge the gap between clients seeking legal advice and professional advocates. It provides secure document storage, direct advocate booking, integrated video consultations (via Jitsi), AI-powered legal document summarization, and curated legal news.

## Features (Phase 3)

### Core
* **Role-Based Access Control:** Separate dashboards and functionalities for Clients, Advocates, and Administrators.
* **Authentication:** Handled entirely via Supabase Auth.
* **In-App Notifications:** Real-time bell notifications for bookings, reviews, and document sharing.

### Client Experience
* **Advocate Discovery:** Search and filter through verified legal professionals.
* **Consultation Booking:** Schedule meetings with advocates based on their availability.
* **Secure Payments:** Integrated with Razorpay Test Mode for seamless checkout.
* **Video Consultations:** Built-in Jitsi Meet integration for remote consultations.
* **Document Vault:** Securely upload and store PDF documents.
* **AI Summarization:** Summarize lengthy legal documents into plain English using the Gemini API.
* **Legal News Feed:** Stay informed with curated legal and political news powered by NewsData.io.

### Advocate Experience
* **Profile Management:** Manage availability, specializations, and consultation fees.
* **Client Management:** View upcoming and past consultations, and access client-shared documents.

### Admin Experience
* **Analytics Dashboard:** View system-wide statistics (total users, verified advocates, total consultations).
* **Verification Flow:** Review and verify advocate registration applications.

## Architecture & Tech Stack

LegalSangam has fully migrated its backend infrastructure to Supabase.

* **Frontend:** React, TypeScript, Vite, Tailwind CSS, Lucide Icons, React Router
* **Backend:** Supabase
  * PostgreSQL (Database)
  * Supabase Storage (Private document storage)
  * Row Level Security (RLS) (Strict data isolation)
  * Edge Functions (Deno backend execution)
* **External Services:**
  * **Payments:** Razorpay
  * **Video:** Jitsi Meet API
  * **AI Summarization:** Google Gemini (1.5 Flash)
  * **News:** NewsData.io

## Supabase Setup

### 1. Database Schema
Execute the SQL scripts located in `supabase/migrations/` sequentially to create the necessary tables:
* `profiles`
* `advocates`
* `availability`
* `bookings`
* `documents`
* `reviews`
* `notifications`
* `news_cache`

### 2. Storage
A private storage bucket named `documents` must be created. Access to documents within this bucket is restricted strictly via RLS policies to the owner and explicitly shared advocates.

### 3. Edge Functions
The following Edge Functions are deployed to Supabase:
* `create-order`: Generates a Razorpay order ID.
* `verify-payment`: Verifies the Razorpay signature.
* `summarize-document`: Extracts and summarizes PDF documents using Gemini.
* `fetch-news`: Fetches and caches categorized news from NewsData.io.

Deploy them using the Supabase CLI:
```bash
npx supabase functions deploy <function-name> --no-verify-jwt
```

## Environment Variables

### Frontend (`.env.local`)
```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_PUBLISHABLE_KEY=your_supabase_anon_key
VITE_RAZORPAY_KEY_ID=your_razorpay_test_key
```

### Backend (Supabase Secrets)
You must configure the following secrets in your Supabase project settings for the Edge Functions to operate:
```env
RAZORPAY_KEY_SECRET=your_razorpay_secret
GEMINI_API_KEY=your_gemini_api_key
NEWS_DATA_API_KEY=your_news_api_key
```

## Security & Disclaimers

### Data Security
* **No Firebase:** All Firebase implementations have been removed in favor of Supabase.
* **RLS Policies:** Every PostgreSQL table is protected by strict Row Level Security policies. Clients cannot read other clients' documents or bookings.
* **Secret Management:** Sensitive API keys (Gemini, NewsData, Razorpay Secret) are **never** exposed to the frontend. They are strictly utilized within secure Supabase Edge Functions.
